# Changelog

## 0.1.3337-1

- Add the initial Home Assistant add-on wrapper for [`ghcr.io/yetone/magpie:0.1.3337`](https://github.com/yetone/magpie/pkgs/container/magpie).
- Persist Magpie settings, provider credentials, accounts, plugins, and usage data in the add-on configuration directory.
- Expose the model gateway on port `3425` and the Magpie web console on port `3430`.
