清理策略

基于本机 HAOS 清理经验、官方文档和社区常见方案整理出的安全边界。

本机清理复盘

  • 主要异常集中在 Docker 存储：构建缓存、未使用镜像和 overlay2 派生占用。
  • 安全清理优先处理 Docker build cache，避免手动删除 overlay2。
  • 备份、数据库、add-on 配置和 Docker volumes 均按用户数据处理，不进入自动清理。

网络经验归纳

  • Docker prune 能回收大量空间，但 `--volumes` 和 `image prune -a` 只能放入深度清理。
  • Recorder 数据库应通过 Home Assistant recorder purge 维护，不直接删除数据库文件。
  • journal vacuum 可减少旧日志，但会损失排障历史，因此需要用户确认。
