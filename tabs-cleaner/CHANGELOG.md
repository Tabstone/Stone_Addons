# Changelog

## 0.1.0-1

- Initial TabS Cleaner add-on.
- Added CleanMyMac-style dashboard.
- Added storage scan, safe cleanup, deep cleanup selection, and history.
- Added smart scan findings, cleanup strategy view, and top-level path profiling.
- Moved Docker system prune from automatic cleanup to confirmed deep cleanup.
- Added parallel scan execution with component timing visibility.
- Rejected confirmed deep-clean requests that contain no executable selected action.
- Added Docker build-context excludes for tests and Python caches.
